# LTT-Dashboard

لوحة تحكم عربية (RTL) للتنبؤ باحتمال مغادرة العملاء (Churn) لشركة الاتصالات والتقنية — LTT.

> **جميع البيانات في هذا المستودع اصطناعية بالكامل.** لا يحتوي على أرقام مشتركين
> حقيقية، ولا أسماء عملاء، ولا سجلّات استخدام أو فواتير فعلية. أُنشئ لأغراض
> التدريب على بناء تطبيقات الويب باستخدام الذكاء الاصطناعي.

## ما في المستودع

يحتوي المستودع على نسختين من اللوحة نفسها:

| المسار | الوصف |
|---|---|
| [`index.html`](index.html) | نسخة مستقلة في ملف واحد — CSS و JavaScript مضمَّنان، والرسوم SVG مكتوبة يدوياً، دون أي تبعية خارجية. تعمل بالنقر المزدوج. |
| [`ltt-churn-dashboard/`](ltt-churn-dashboard) | نسخة Next.js + TypeScript + Tailwind، مقسَّمة إلى مكوّنات، ومعها مسار API. |

النسخة المستقلة كانت النموذج الأول (prototype)، ونسخة Next.js هي الأساس الذي
يُبنى عليه لاحقاً عند إضافة قاعدة بيانات.

## المزايا

- **بطاقات مؤشرات** — إجمالي العملاء، المعرَّضون للمغادرة، المعدل المتوقع، الإيراد المعرَّض للخطر.
- **اتجاه المغادرة** — رسم خطي يقارن المعدل الفعلي بالمتوقع خلال 12 شهراً، مع تتبُّع تفاعلي.
- **توزيع مستوى الخطر** — رسم دائري قابل للنقر لتصفية الجدول.
- **أسباب المغادرة** — وزن كل سبب في تفسير تنبؤات النموذج.
- **جدول العملاء** — قابل للفرز والتصفية والتصدير، مع إجراءات لكل عميل.
- **تحليل عميل فردي** — نموذج تفسيري يُخرج النسبة والتصنيف وأهم العوامل والإجراء المقترح.
- **ست صفحات** — الرئيسية، تنبؤات العملاء، تحليل الشرائح، تنبيهات الخطر، التقارير، إعدادات النموذج.

الفلاتر تعمل على المنطقة ونوع الباقة وفترة الاشتراك ومستوى الخطر، وهناك حالات
تحميل وحالات فراغ صريحة، وتصدير إلى CSV و PDF، ووضع فاتح وداكن.

## التشغيل محلياً

```bash
cd ltt-churn-dashboard
npm install
npm run dev
```

ثم افتح http://localhost:3000

للنسخة المستقلة: افتح `index.html` في المتصفح مباشرة — لا تحتاج إلى أي تثبيت.

## الأوامر

```bash
npm run dev     # خادم التطوير
npm run build   # بناء الإنتاج
npm run lint    # تدقيق ESLint
```

## مسار API

```
GET /api/customers
```

معاملات اختيارية: `region`، `plan`، `risk` (high|mid|low)، `tenure` (t1..t4)،
`sort`، `dir` (asc|desc).

كل قيمة تُتحقَّق مقابل قائمة مسموح بها **على الخادم**؛ القيمة غير الصالحة تُرجع
`400` مع بيان القيم المسموح بها. المبدأ التدريبي: لا تُفترض صلاحية أي مُدخل لأن
الواجهة تُقيّده، فالواجهة قابلة للتجاوز.

مثال:

```bash
curl "http://localhost:3000/api/customers?risk=high&sort=bill&dir=desc"
```

## ملاحظات تقنية

**ألوان الرسوم مُتحقَّق منها.** سلسلتا الرسم الخطي تجتازان فحوص التباين وعمى
الألوان في الوضعين الفاتح والداكن. لكن فارق التريتان بين الأزرق والتركوازي
منخفض، لذا **التمييز بالخط المتقطع ومفتاح الرسم والجدول البديل ضرورة وصولية
ولا يجوز حذفها** — لا يعتمد التمييز على اللون وحده.

**اتجاه RTL.** الخصائص المنطقية (`inset-inline-start/end`) تنقلب في RTL، لذا
العناصر المثبَّتة على الحافة اليمنى (الدرج والشريط الجانبي على الجوال) تستخدم
إحداثيات فيزيائية. ومحور الزمن في الرسم الخطي يتدفّق يميناً←يساراً. ولا يُستخدم
`letter-spacing` مع النص العربي لأنه يقطع اتصال الحروف.

## المرحلة القادمة

لم تُضَف قاعدة البيانات بعد. النموذج الحالي بيانات ثابتة في `src/lib/data.ts`،
والخطوة التالية هي ربط Supabase وفصل القراءة والكتابة عبر مسارات API.
